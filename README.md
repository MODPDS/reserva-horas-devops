# Reserva de Horas Médicas – Proyecto DevOps

Servicio web estático que simula la reserva de horas médicas de un centro de salud.
Se sirve con **Nginx** dentro de un contenedor **Docker** y se ejecuta localmente con **Docker Compose**.

> Proyecto académico (IACC – DevOps, Semana 3). El repositorio está en construcción;
> las instrucciones completas de instalación, ejecución y verificación se agregan en la rama de trabajo.
